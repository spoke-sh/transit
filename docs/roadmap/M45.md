# M45: Mutation completion and authority efficiency

Status: implemented and qualified; pending merge under [issue #73](https://github.com/rupurt/rey/issues/73).
Follows the qualified M43 baseline and M44
in the linear roadmap; does not reopen their completed scope.

## Question and scope

Reduce the cost between durable Table admission and an authorized terminal
result. The baseline is merged source `96943293`; the observed 106 ms console
write includes 78 ms in a combined worker/observation phase. Embedded durable
DuckDB and SQLite controls establish a useful local comparison, not equivalent
distributed execution contracts or a promised Transit latency target.

1. Freeze ReleaseSafe console/direct-caller controls on physical disk. Retain
   raw samples, binary hashes, provider settings and failed/incomplete runs.
2. Replace fixed completion polling with shared bounded authorized waits.
   Preserve exact saved requests, current disclosure, cancellation, registration
   races, remote publication reconciliation and ordinary-read capacity fallback.
3. Attribute admission, worker scheduling/view/turn requests and completion
   observation separately. Measurements must distinguish client sleeps, queueing,
   provider work and durable decisions without logging payloads or credentials.
4. Measure and reduce redundant provider work and sequential staging dependencies.
   Preserve atomic root publication, verified acknowledgements, original receipt
   recovery, retained roots and explicit resident bounds.
5. Measure contention and finite offered load separately from isolated latency.
   Evaluate ephemeral execution views, preparation outside serialized authority
   and group commit against their missing publication/recovery contracts; enable
   none merely on the strength of a happy-path latency result.

## Owners and qualification

Shared client/Station owners retain protocol semantics; SQL and application
handlers remain outside core authority. Provider work belongs in the backend.
Console timing and the owned mutation harness expose measurements, not another
source of authority. Completed input and matching terminal status remain distinct
from send acknowledgement and notification hints.

Run package/root checks, real caller and service wait/recovery proofs, storage
fault schedules for backend changes, independent measurement controls and clean
committed-source CI. Retain worker replacement, denied observations, lost receipts,
capacity exhaustion, cancellation and cold retained-root tests. Publish current
behavior in the component guides and public performance reference; put scientific
reasoning in the existing storage-runtime account and executed evidence in tests.

Coordinate with #70's complete change coverage and asynchronous maintained state,
#31's explicit schema/branch roots and #71's independent compute vectors. A wake
hint is not a change feed; adding replicas is not authority sharding. This work
does not select a throughput SLO, weaken durability or enable an alternate SQL
write authority. Any incompatible protocol change needs the coordinated current
v1 cutover required by the versioning policy.

## Delivered result and evidence

Shared caller waits replace fixed mutation polling. Independent leaf rewrites
stage in bounded groups before parent construction, with verified acknowledgements
and unchanged atomic root publication. Correlated measurements separate admission,
view/turn work and caller observation without exposing values or credentials.
The physical-disk console control reduces INSERT/UPDATE/DELETE medians from
142/153/138 ms to 113/130/112 ms. Concurrent reads, finite overload/refusal,
paced admission, cold retained roots and exact recovery remain separately scoped.

Full pinned `just check` and all 75 ordinary tasks in one clean committed-source
run pass at `be0e03d1547bfa5aadc38c199068f49594e2906c`. The selected exhaustive
resource campaign covers 1,170 replayed traces. The [proof ledger](../../tests/README.md#mutation-completion-follow-up)
and [raw measurement archive](../../tests/mutation_latency/results/2026-10-05/README.md)
retain the exact revisions, results and limitations, including development failures.

Ephemeral execution views, preparation outside serialized authority and group
commit remain evaluated alternatives with explicit missing contracts in the
[storage account](../internals/storage-runtime.md#alternatives-and-contract-boundaries).
They are not enabled by this milestone. Sustained multi-writer SQL throughput,
horizontal authority scaling and embedded-engine latency parity remain unproved.
