# M43: Durable Table mutation latency

Status: in progress. Tracked by [issue #55](https://github.com/rupurt/rey/issues/55).
Follows M42 in the linear roadmap; extends M30's shared storage work and M36's
bounded mutation owner without enabling additional SQL syntax or transactions.

## Scope and sequence

1. Correct console timing and add a reproducible end-to-end mutation fixture with
   frozen ReleaseSafe binaries, owned disk providers, raw samples, independent
   state verification and explicit failed/incomplete outcomes.
2. Measure console/direct callers, bounded row batches, absent/existing keys,
   independent retained-history and row counts, cache controls, worker polling
   and concurrent reads. Separate instrumented request counts from elapsed-time
   controls; keep TPC component and full-workload coverage distinct.
3. Add bounded request/work/storage counters independent of diagnostic sampling.
   Reduce repeated caller/worker reads and batch compatible catalog writes.
4. Implement bounded direct admission for small mutation requests, preserving
   exact identity, current authorization, atomic rows/outcomes, uncertain retries,
   cancellation and the existing four-mutation/value limits. Coordinate any
   incompatible native/framework definition cutover across generated resources,
   signing fixtures, SDKs, saved artifacts and public documentation.
5. Diagnose connection lifetime failures and evaluate worker wake-up behavior
   after reducing per-operation work. Faster polling is a measurement control,
   not sufficient evidence of a scheduling improvement.

## Qualification

PRs #57 and #59 deliver timing, bounded counters, batched reads/catalog writes,
small-mutation direct admission, the experiment harness and closing-response
socket ownership. Follow-up work adds bounded console observation retries and
archives failed and completed controls. Default and idle console controls now
complete 20 samples per case. These historical fixed-poll controls still fail during uncertain sends and
increase idle traffic; the continuation below supersedes their polling-only
scheduling mechanism. The original failed controls remain in the evidence.

The continuation implements complete command candidates, shared preparation and
outcome reads, fewer console recovery checkpoints, bounded authorized worker
notifications, and compact 8/32 immutable pages. The compact format hard cutover
migrates the current definition, generated consumers and independent signing
fixtures together. Hot/closed/S3 page recovery, resource fault simulation,
server/service lifecycle, notification cancellation and remote-node timeout
reconciliation pass at their recorded sources. New failures retain original
operation identities; a subsequent successful control does not resolve them.

The layout experiment rejects separate control/data roots as a point-write
optimization for its measured workload; ownership/branch work remains coordinated
with issue #31. View leases, preparation outside serialized access and group
commit remain evaluated alternatives, with explicit missing authority/recovery
contracts, rather than enabled runtime shortcuts. Notification hints do not
supply issue #70's complete change coverage. Storage pages remain independent
of issue #71's vector and publication budgets.

Clean qualification exposed a physical-storage query-delivery timeout hidden by
tmpfs-focused runs. Follow-up work batches captured/received query fragment reads
and reports failed phase costs. Complete clean qualification remains open; see
the proof ledger for exact revisions and failures.

Keep existing installations intact. Record baseline/candidate provenance and
source/fixture limits, not an implicit latency SLO or a TPC score. Require
lost-response recovery, fresh fenced ownership, current revocation, stale views,
atomic row/outcome visibility, cancellation and retained data beyond cache.
Run focused proofs and full checks, then committed-HEAD clean qualification
before pushing. Preserve failure evidence and unexecuted gates explicitly in
the proof ledger and tracking draft PR.
