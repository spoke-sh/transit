# M13 — gRPC connector and streaming calls

[Roadmap](README.md)

Status: Planned; builds on [Station M9](M9.md), [HTTP M12](M12.md) and the shared
effect/transcript/lifetime contracts. gRPC is the second connector.

Scope: a Zig-native transport, Station call helpers and trusted connector worker
for unary and bounded server-, client- and bidirectional-streaming RPCs.
[GRPC.md](../GRPC.md) owns the design; [M14](M14.md) reuses the transport for Arrow
interoperability without treating network streams as durable mailboxes.

## Entry gates

| Gate | Required decision / evidence |
| --- | --- |
| Native transport | Select immutable Zig-compatible HTTP/2/protobuf/TLS dependencies; prove generation, trailers, message framing, compression bounds, flow control and cancellation against independent peers |
| Streaming authority | Specify exact committed send units, current authorization, executor fencing, half-close/completion and result acceptance; identify/prove any required versioned kernel extension |
| Transcript and capacity | Reuse M12's durable payload/dependency contract; budget live calls, each direction's messages/bytes, capture, outboxes and control headroom |
| Retry behavior | Prove transport, resolver and service configuration cannot create unrecorded RPC attempts; specify method idempotency and finite reconciliation before dispatch |

## Exit criteria

- [ ] Publish versioned language-neutral call, descriptor, transcript and result
  contracts. Generate typed helpers from pinned service schemas without hidden
  network I/O; expose the common surface through Station's shared bindings.
- [ ] Exercise all four call shapes against independent gRPC peers using
  synthetic services. Qualify framing, binary metadata/trailers, half-close,
  terminal status and explicit finite call/byte/message limits.
- [ ] Commit every outgoing message/batch before authorizing that work; prove
  revocation/work-cutoff races, executor handoff, stale owners and blocked peers.
  An initial call permit cannot authorize arbitrary future sends.
- [ ] Persist ordered request/response observations, capture omissions and
  terminal coverage before publication. Distinguish provisional responses,
  transport failure, method status and authoritative result acceptance.
- [ ] Prove bounded backpressure in both directions, oversized/decompression
  rejection, cancellation with in-flight messages, transcript exhaustion and
  control progress on a constrained worker.
- [ ] Inject worker/authority failure before send, after remote execution, during
  partial streams and before final capture. Recover recorded state without
  inventing rollback, replaying a partial request stream or silently redialing.
- [ ] Reject hidden retries/hedging; exercise an explicit idempotent-method retry
  and a non-idempotent unknown outcome. Close reconciliation within its recorded
  bounds and reject late results without claiming the remote operation stopped.
- [ ] Prove TLS/authority/method/credential scope, alternate-endpoint rejection,
  forged result rejection, current transcript access and secret-safe capture.
- [ ] Replay captured calls with network and secret resolution disabled.
- [ ] Ship a Zig reference caller plus binding fixtures, a connector worker and
  local/Compose/reference launcher configuration. Prove reference worker loss
  and effect isolation; use independent implementations only as test peers.
- [ ] Add bounded service instrumentation and Board call/attempt metadata views
  without application protobuf decoders or credentials in logs/transcripts.

## Outside this milestone

Generic hosting of application RPC servers, gRPC-Web, unlimited live sessions,
automatic resume without a remote acknowledgement/deduplication protocol, and
exactly-once remote effects are not promised. Flight/Flight SQL and ADBC client
qualification belong to [M14](M14.md). Missing transport or streaming authority
is an entry gate to resolve, not permission to ship a unary-only milestone under
the full streaming scope.
