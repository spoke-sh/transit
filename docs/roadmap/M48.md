## Scope and delivery sequence

Fuze owns bounded physical columns and kernels; hosts own source acquisition,
current authorization, scheduling and publication. Implement in these slices:

| Slice | Work | Required evidence |
| --- | --- | --- |
| V0 | Freeze scalar workloads, source/compiler/CPU identity, independent results and numerical budgets; audit pinned compute reuse and CPU dispatch | Kernel, complete pipeline and real adapter measurements, with raw failures retained |
| V1 | Owned/borrowed flat and constant columns, all five states, stable selections/provenance, immutable bound plans and byte/work budgets | Lifetimes, allocation failure, competing errors, cancellation and resident bounds |
| V2 | Single-thread batched scalar comparison/state/eager Boolean, projection, COUNT and ordered checked int64 SUM; Unified and logical/native/file adapters | Independent outputs and first failures, complete-file validation, packing cost and small-query latency |
| V3 | Portable and runtime-qualified AVX2 kernels; measured selective fusion | Forced supported dispatch, tails/alignment, baseline-safe artifacts and generated instructions |
| V4 | Enabled callers, Arrow lifetimes and finite/captured/maintained relational paths | All 315 independent relational cases, checkpoint/rebatching, exact deltas, native recovery/current denial and affected installed callers |
| V5 | Host-owned bounded parallel compute over decoded eligible filter/project/COUNT batches | Ordered coordinator, serial acquisition, 1/2/4-worker comparisons, bounded queues, cancellation and control progress |
| V7 | Select measured defaults, remove superseded plumbing and qualify integrated behavior | Precommitted budgets, full/focused checks, committed-source clean CI and public documentation |

V6 tracks optional later hardware, layouts, JIT/GPU, new join algorithms and
incremental maintenance. It is not part of the selected closure criteria.
Initial hot types are int64, uint64, finite float64 and bool with already admitted
operators. Rich types retain correct generic kernels. Initial hardware is Linux
x86_64 portable plus qualified AVX2; neither other hardware nor universal speedup
is promised.

The first implementation PR delivered V0/V1 and a narrow V2 vertical slice:
owned int64 comparison, selection, projection and COUNT through one general Table
adapter and one frozen file adapter. Its selector stayed internal to tests and
benchmarks. That PR did not close #71; the integrated delivery below completes
the remaining selected scope.

## Invariants and experiment contract

Storage pages, validation pages, compute vectors, Arrow batches and publication
chunks remain separate. Source validation precedes operators within its original
boundary; later acquisition failures cannot outrank earlier operator failures.
File projection/filter/LIMIT still validates every field and verified EOF.
Eager Boolean errors and every checked SUM prefix retain their original order.
The sequence `[MAX_I64, 1, -1]` must fail on its second contribution.

Keep FZS1/FQS1 progress, relational logical work/cursors/group roots and exact
Arrow/exchange/revision/delta identities. Private lookahead is not accepted
progress. Recheck current rights before every disclosure, including buffered,
empty and terminal results. No CPU choice grants authority or changes recovery.
Any unavoidable incompatible public/persisted change requires the shared current
v1 cutover and migrated consumers; an internal representation alone does not.

Sweep 64/256/1024 compute rows and 64 KiB/256 KiB/1 MiB total batch budgets,
always capped by the enclosing query. Account for columns, state sidecars,
selection/provenance, scratch and all queued/active workers. Flush short work
promptly. The sweep measures costs without raising public limits; the integrated
delivery above records the selected defaults. Native four-write/256-byte and
existing Arrow output/workspace bounds remain.

Freeze workload-specific numerical thresholds before candidate tuning. Preserve
existing file budgets and all eight native control ratios at or below 1.15.
Separate scalar, batched scalar, SIMD, fused and parallel costs; measure complete
pipelines as well as decoded kernels. Record ReleaseSafe/compiler/dependency
identity, CPU/affinity, fixture hashes, setup/first-result/completion, allocations,
memory and attribution limits. Retain failures and insufficient evidence.
