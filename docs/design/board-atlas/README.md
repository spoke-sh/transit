# Board design materials

Start with the [design review index](../README.md) for the numbered sequence,
summary table and recorded outcomes. This directory holds supporting material
for [D1](../D1.md), [D2](../D2.md) and [D3](../D3.md).

- [Images](images/): the thirteen original generated figures, unchanged.
- [D1 interaction and evidence specification](INTERACTIONS.md).
- [D1 generation prompts](prompts.json).
- [D2 fabric and age prompts](fabric-prompts.json).
- [D3 scale prompts](scale-prompts.json) and [synthetic fixture](scale-fixture.json).

The PNGs are design references, generated with the built-in image tool and
stored without raster post-processing. They are not embedded application assets.
Review decisions and discussion live in the numbered documents.
