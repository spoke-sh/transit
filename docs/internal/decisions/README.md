# Architecture decisions

This directory is reserved for future architecture decision records (ADRs).
For now, technical choices and their rationale live in the
[foundational documents](../../README.md). There are no decision records yet.

When separate records become useful, use them for choices that materially affect
contracts, operations, dependencies, or future changes. Number records in order,
use short descriptive filenames, and list them here.

Copy [TEMPLATE.md](TEMPLATE.md) when documenting a decision. Use `Proposed`,
`Accepted`, `Rejected`, or `Superseded` status. Accepted means the choice has been
made; it does not imply implementation is complete. Link replacement ADRs when
superseding a decision and retain the old rationale.
