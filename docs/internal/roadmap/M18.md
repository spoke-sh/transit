# M18 — Unified state querying and versioned source contracts

[Roadmap](README.md)

Status: Complete for the declared growing profile on Linux x86_64; follows [Documents M17](M17.md), using [M12 SQL](M12.md),
[M13 public queries](M13.md), [M14 publication](M14.md) and the reusable reference/
availability patterns qualified by [M15](M15.md)/[M16](M16.md).

Scope: query KV, Table and accepted Document state through one Zig Fuze expression,
plan and Arrow result model, with versioned decoders, projections and public
request/result interfaces. This milestone owns the unified-query obligations
formerly coupled to Document implementation. [M19](M19.md) composes these public
queries with HTTP serving; [M20](M20.md) qualifies reactive API hosting and
[M21](M21.md) consumes it for reactive refresh.
Remote Flight/ADBC is [M22](M22.md).

## Why this is a separate contract step

M13's qualified schema is an int64 key plus one nullable scalar column; its public
Station request leaves 207 encoded plan bytes. M14 adds opaque immutable records,
not larger wire frames or Arrow types. M17 adds Document semantics, not a query
engine. Preserve those working profiles and add explicit versions/capabilities
rather than silently changing v1 schema, request or result interpretation.

| Layer | Reuse | Work owned here |
| --- | --- | --- |
| Station KV/Table/Document | Resource grants, retained versions and bounded accepted-state readers | Source adapters, declared KV decoders and Document projections; no mutation/merge logic in Fuze |
| M14 publication and connector reference patterns | Segmented immutable storage, bounded reads, current availability and lifetime checks | Qualify larger plan/schema submission and manifests, including reference authorization, cleanup and commitment uncertainty |
| Fuze and SQL | Existing operator semantics, parser corpus, plan validation and paged execution | Versioned schemas/expressions, nested Arrow, path/list/text operations and exact decoder/type evidence |
| M13 public query hosts, shell and Board workspace | Explicit query identity, request/retry/cancel semantics and verified result delivery | Publish new capabilities across source kinds without weakening current policy checks or original Table compatibility |
| M11 SDKs | Shared Zig semantics, scoped native ownership and full-width values | Native typed unified-query APIs and cross-language source/Arrow fixtures |

The selected [v2 contract](../../../contracts/UNIFIED_QUERY_V2.md) is implemented:
versioned source adapters and typed plans, nested Arrow, finite authenticated
uploads, retained capture and verified complete-result manifests. All ten M11
SDKs pass the installed service matrix across KV, Table and accepted Document.
The existing SQL parser lowers to this shared plan; no optimizer rewrite is enabled.

The shell and separately authorized Board API/browser pass all three sources,
including frozen retry, current prefix denial and complete provenance. Signed
lifecycle and real-clock expiry proofs cover each source. Runnable finite SQL
examples preserve original intent across process restart; Table additionally
passes Compose and Substrate worker/node/store recovery with scoped identities
and network isolation. KV/Document physical placement is not claimed. The
[proof ledger](../../../tests/README.md#m18-qualification) records measured tasks,
failed attempts and limits. The original public Table v1 path still passes.
Expanded hosted CI costs remain deferred under the existing CI decision; this
qualification does not establish new hosted feedback budgets. The
[M19–M30 handoff](README.md#m15m18-handoff-to-m19m30) carries these findings into
the next planned milestones without expanding this completed profile.

## Entry gates

1. Fix versioned source/schema/decoder identity, declared KV key/value decoders,
   supported Document projections and output types. Distinguish missing, explicit
   null, type error and unresolved conflict; none may silently become another.
2. Define bounded path lookup, list expansion and materialized-text projection,
   overflow/error ordering and unsupported shapes. No full-text index, continuous
   query or arbitrary application callback runs inside kernel authority.
3. Choose explicit plan/request/schema/result versions and capability negotiation.
   Measure the full encoded public request, continuation, metadata and Arrow
   segment sizes. Larger immutable records cannot silently widen a mailbox frame.
4. Specify exact source cuts and retained-read ownership. Reject unsupported
   cross-resource snapshots/transactions even though adapters share expressions.
5. Map new operator/type behavior to reference evaluators and M12's proof
   assumptions. No optimizer rewrite is enabled solely because a specification
   theorem exists or because the scalar Table implementation passed.

## Implementation sequence

1. Publish neutral source/decoder/projection/plan/result contracts and shared
   fixtures. Define compatibility and error behavior before language conveniences.
2. Implement KV and Document adapters over their bounded public readers, with
   Table as the regression baseline. Record exact committed source, schema,
   decoder, Document type/change format and projection revisions in results.
3. Extend Fuze plans/operators and Arrow ownership/codecs for the selected types.
   Qualify nested encodings against independent Arrow readers; keep evaluation
   Zig native without DataFusion/Acero runtime dependencies.
4. Extend public submission/cancellation/result delivery and the SQL/frontend
   capability matrix. Reuse durable references and verified completion; no silent
   truncation, speculative source substitution or whole-result buffering.
5. Extend every M11 SDK and the existing shell/Board query surface through shared
   Zig APIs. Run same-plan/reference results, authority/failure and interoperability
   fixtures, then record the supported source/protocol matrix for M19–M22.

## Exit criteria

- [x] Query KV, Table and Document through the same typed expression/plan/result
  interface. KV requires a declared versioned decoder; Document reads use M17's
  accepted-state contract. Unsupported decoders/types/expressions reject explicitly.
- [x] Preserve missing/null/type-error/conflict distinctions, bounded list expansion
  and materialized text; prove error/overflow/order semantics with independent
  evaluators and batch/page-boundary permutations.
- [x] Return qualified primitive/nested Arrow types with exact committed source,
  schema/decoder/projection identity. Empty, null, conflicting, binary, Unicode
  and full-width values retain meaning across consumers.
- [x] Version and advertise the wider public request/schema/result surface while
  keeping M13 Table requests and retained results readable under their original
  contract. Reject unknown versions, wrong digests and oversized work before
  acceptance; references are never bearer grants.
- [x] Qualify source/result access revocation before submit, during capture, after
  an actual returned prefix and after completion, plus expiry, retained-version
  release, retirement, worker/node restart and exact signed retry for every source.
- [x] Preserve bounded execution, resumable progress, complete-result manifests,
  current policy rechecks, cancellation distinctions and cleanup. Test larger
  plans/results than the old frame and row bounds without widening kernel limits
  or creating a second authoritative store.
- [x] Qualify each enabled optimization against the reference semantics, including
  errors/conflicts and source revision. If no rewrite is enabled, say so; retain
  M12's theorem/implementation boundary and prove new rules before enabling them.
- [x] Every M11 SDK exposes unified queries over shared Zig with runtime boundary
  validation and owned Arrow results. Run shared decoder/projection/Unicode/Arrow
  fixtures and cross-language round trips across all source kinds.
- [x] Extend the public shell and optional separately authorized Board query
  workspace with truthful source capabilities, exact provenance and denied/gap
  behavior. Board inspection remains distinct from query authorization and does
  not acquire arbitrary business-value decoders.
- [x] Add runnable non-trading examples, local/Compose/reference query recovery
  proofs, bounded service signals, component usage/recovery guides and measured
  CI tasks. Hand M19–M22 an explicit source/type/protocol compatibility matrix;
  finite source adapters do not imply a watch/change-feed API.

## Boundaries

No new mutation/DML or CRDT semantics, implicit KV schema inference, automatic
schema migration, cross-resource joins/transactions, distributed execution,
full-text indexing or continuous materialization. SQL only exposes operations
that compile to the qualified shared plan; it is not a separate execution path.
A shared adapter model does not require every future protocol to expose every
source immediately. M22 starts with qualified Table access and explicitly adds
other combinations only with their own client/protocol evidence.
