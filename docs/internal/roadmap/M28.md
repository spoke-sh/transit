[Roadmap](README.md)

## Scope and owners

- `apps/transit-cli` owns concise human diagnostics and offline command help.
  Known invocation failures name the option and correction once. File/schema
  failures retain useful escaped coordinates. Unexpected failures retain their
  identifiers; uncertain operations retain exact-retry guidance.
- Root and application-group help list commands. Command help describes only
  supported options, including new per-operation application help.
- The [CLI reference](../../reference/cli.md) owns current output semantics;
  [CLI v1](../../../contracts/TRANSIT_CLI_V1.md) retains explicit configuration,
  command validation, stdout/stderr, exit codes and recovery contracts.
- `tests/cli_diagnostics.py` checks the real executable. Existing server and
  console proofs retain readiness, recovery, shutdown and machine-record checks.

No verbosity flag, startup output mode, configuration discovery or protocol
change is included. Existing server JSON records and console results remain.

## Exit criteria

- [x] Concise routine errors, selective usage/help and useful locations pass
  real-command checks without argument/configuration/credential disclosure.
- [x] All command help works offline; invalid input still rejects before effects.
- [x] Unknown causes, restart exhaustion and uncertain outcomes remain distinct.
- [x] Existing server and console recovery checks and `just check` pass.
- [x] Public documentation and design outcome match implementation; actual
  commands and limits are recorded in the [proof ledger](../../../tests/README.md).

`just check` passes, including 125 real CLI cases and diagnostic recovery checks.
`just test::server`, `just test::server-faults`, `just test::console table` and
`just test::server-board` pass. Exact schedules, measured costs and the Table
console scope are recorded in the [proof ledger](../../../tests/README.md#cli-diagnostic-qualification).

Clean committed-HEAD qualification remains a pre-push gate; local working-tree
checks do not establish it. Publication and clustered portability move to M32
