# Working on qualification history

Follow the [documentation rules](../../AGENTS.md). This directory holds accepted
qualification accounts grouped by technical subject. The [index](README.md) is
navigation, not a daily progress log. Current interface semantics remain in the
handbook; ongoing work and handoffs remain in issues/PRs.

Keep the question, exact source/configuration, executed method, outcome and limits
together. Link raw evidence and the current semantic owner. Preserve failures and
uncertainty even when a later run passes. Never promote component evidence into
an installed, provider or whole-suite claim.

Consolidate related experiments within their topic. When moving an older record,
preserve its original claims and source attribution, update relative links and
retain an auditable mapping. Do not reinterpret old commands as current workflows.
Run the documentation link check and inspect diff whitespace after changes.
