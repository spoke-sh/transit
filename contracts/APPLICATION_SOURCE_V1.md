The current source-language contract is owned by [transitc](https://github.com/spoke-sh/transitc/blob/main/contracts/APPLICATION_SOURCE_V1.md).
Transit consumes the [exact pinned definition](../third_party/transitc/contracts/APPLICATION_SOURCE_V1.md)
and [grammar/model/corpus](../third_party/transitc/contracts/application-source/README.md)
with its compiler snapshot. Runtime SQL, protocol, migration application and test
hosting retain their existing Transit owners. The extraction does not change the
current-v1 definition identifier or reinterpret accepted SQL/history.
